## ⚙️ Funcionalidades

| Função | Descrição |
|:--------|:------------|
| ➕ **Adicionar contato** | Permite ao usuário adicionar um novo contato (nome e telefone). |
| 📋 **Mostrar contatos** | Exibe todos os contatos cadastrados. |
| 🚪 **Sair** | Encerra o programa de forma segura. |

## 💻 Como Usar

### 1️⃣ Requisitos

- Compilador **C++11 ou superior** (G++, Clang, MSVC, etc.)
- Terminal ou IDE compatível (Code::Blocks, Visual Studio, VSCode, etc.)
